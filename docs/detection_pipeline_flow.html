Alur Logika Audio & Deteksi Kata Kotor (Warnet Environment)

Membedah kenapa akurasi saat ini < 30% dan bagaimana desain deterministic deterministik mencapai 95%+ di lapangan.

Kondisi Saat Ini (Broken Engine)

~15% - 25% Akurasi Nyata
Bocor suara tetangga (amplified 20x), loop gantung di mic bising, context exclusion terhapus, gamer sebut 'player' di-lockdown.

Kondisi Setelah Solusi (Hardened Pipeline)

> 95% Akurasi Nyata
Noise gate buang suara jauh (<0.05 & 0.31-0.45 RMS), STT kirim audio jernih anti-clip, regex whole-word presisi tanpa salah sasaran.
🛡️ Arsitektur Alur Logika Sebenarnya (Step-by-Step)
Tahap 1 Acoustic Capture

Mikrofon Desktop & Noise Floor Auto-Tune

Buka stream mic via PyAudio. Panggil adjust_for_ambient_noise(source, 1.0) sekali saat boot untuk mengukur desis ruangan warnet.

Saat Ini: Hardcode 150 Fix: Baseline dinamis per mic
↓
Tahap 2 Proximity Gate

Hardware Level Noise Gate (RMS Linear Filter)

Hitung RMS chunk lokal. Evaluasi zona:
• 0.00 - 0.05 (Desis AC/Kipas) → DROP
• 0.06 - 0.30 (Suara Mulut User) → PROCESS
• 0.31 - 0.45 (Teriakan PC Sebelah / Bocor) → DROP
• 0.46 - 1.00 (Teriakan Dekat User) → PROCESS

Saat Ini: 0% filter (belum dipasang) Fix: 100% suara jauh dibuang
↓
Tahap 3 Audio Conditioning

Controlled Soft-Limiter & Resampling

Jangan boost 20x. Gunakan gain maksimal 3x dengan soft limiter (mencegah clipping kotak). Resample ke 16kHz bersih jika hardware hanya support 44.1k/48k.

Saat Ini: Clip kotak + noise aliasing Fix: Gelombang utuh terbaca Google
↓
Tahap 4 Speech-to-Text

Google Speech Cloud STT (id-ID) dengan Time-Limit

Kirim audio dengan parameter PHRASE_TIME_LIMIT = 5.0 dan timeout 10s. Terima string transkrip murni. Masukkan ke antrean FIFO agar tidak balapan.

Saat Ini: Hang di suara bising warnet Fix: Perekaman terpotong rapi per frase
↓
Tahap 5 String Normalizer

Normalisasi Karakter Tanpa Merusak Teks Asli

Lowercase + strip tanda baca. Jalankan re.sub(r'(.)\1{2,}', r'\1', text) untuk mereduksi huruf teriak (kontooool → kontol). Simpan transkrip asli untuk log audit.

Saat Ini: 'kontooool' lolos 100% Fix: Makian teriak tertangkap
↓
Tahap 6 Context Guard

Prioritas 1: Context Exclusion & Clean Mapping

Hapus 'player' dari kamus. Cek apakah ada frasa pengecualian (dealer honda, peeler kentang) sebelum mencocokkan kata hitam. JANGAN hapus kata konteks dari memori teks!

Saat Ini: 'dealer honda' jadi 'peler' Fix: Frasa normal langsung SAFE
↓
Tahap 7 Strict Blacklist Match

Prioritas 2: Whole-Word Regex Matching (\bword\b)

Lakukan matching O(1) set tokens untuk kata tunggal, regex boundary untuk frasa majemuk. Zero tolerance untuk kata kelamin fatal tanpa kompromi.

Saat Ini: 'kontrol' terancam salah deteksi Fix: 'kontrol' ≠ 'kontol' 100% aman

HASIL: SAFE (Abaikan / Log Normal)

  • Audio di bawah threshold atau masuk zona desis/suara jauh.
  • Mengandung kata pengecualian konteks (misal: "honda", "kentang").
  • Tidak ada kata hitam yang lolos regex boundary.
  • Operasional warnet tetap tenang, pelanggan bermain tanpa gangguan.

HASIL: TOXIC CONFIRMED (Eksekusi Sanksi)

  • Audio terbukti berasal dari mulut user (RMS zona valid).
  • Kata hitam eksak terbukti diucapkan tanpa konteks pelindung.
  • Tingkat sanksi diputuskan oleh PenaltyManager (Warning / Lockdown).
  • Log tersimpan rapi dengan transkrip mentah sebagai bukti otentik.
